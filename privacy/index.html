요약

검은 미사는 이메일, 전화번호, 위치, 연락처 같은 개인 정보를 수집하지 않습니다. 광고와 추적 기능이 없고, 앱 내 구입도 없습니다. 랭킹과 보스 공유(챌린지)를 위해 Apple Game Center 계정의 플레이어 ID와 이름, 그리고 게임 안의 정보만 게임 서버로 보냅니다.

Game Center 로그인

게임은 기기에 로그인된 Apple Game Center 계정으로 자동 로그인합니다. 이때 Apple이 이 게임에 주는 플레이어 ID(teamPlayerID)와 Game Center 이름을 받습니다. 게임 서버는 Apple의 서명을 Apple 공개 키로 확인해 본인임을 확인합니다. 비밀번호나 Apple ID 이메일은 받지 않습니다.

Game Center에 로그인하지 않아도 게임을 할 수 있습니다. 이 경우 게임 서버에서 챌린지 목록만 받아오고 플레이어 정보는 보내지 않으며, 보스 공개·신고·차단과 랭킹 등록은 쓸 수 없습니다.

게임 서버로 보내는 정보

Game Center에 로그인되어 있고 인터넷에 연결되어 있을 때, 아래 정보를 게임 서버(api.isacshin.com, Cloudflare에서 운영)로 보냅니다.

기기에만 저장되는 정보

진행 상황, 코인, 장비, 설정, 강령 제단에서 만들었지만 공개하지 않은 보스는 기기 안에만 저장됩니다. 앱을 삭제하면 함께 지워집니다.

보관 기간과 삭제

공개한 보스는 강령 제단에서 그 보스를 삭제하면 서버에서도 함께 지워집니다. 랭킹 기록, 공개한 보스, 플레이어 ID와 이름은 서비스를 운영하는 동안 보관합니다. 모두 삭제를 원하시면 Game Center 이름을 적어 아래 이메일로 요청해 주세요. 확인 후 지체 없이 삭제합니다.
